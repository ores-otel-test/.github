# Security policy

## Canonical organization links

- GitHub organization: https://github.com/ores-otel-test
- Public organization defaults: https://github.com/ores-otel-test/.github
- Canonical Linear project: https://linear.app/denman/project/githubcomores-otel-85e70d77275a
- Fleet tracking issue: https://github.com/ORESoftware/k8s-cluster/issues/1222

Do not disclose vulnerabilities, exploit details, credentials, personal data, production data, or private infrastructure information in a public issue, discussion, pull request, commit, or Linear comment. Use GitHub private vulnerability reporting when available, or contact organization maintainers through a verified private channel.

Include the affected repository and revision, impact, prerequisites, reproducible steps, and a minimal proof of concept with secrets and private data removed. Preserve evidence non-destructively.
